# AWS DevOps Financial Showcase

A reproducible DevOps portfolio built around synthetic financial operations:
ingest an event, open an incident, follow its trace, detect a failure, recover a
workload, and restore its database. Infrastructure and delivery have runnable checks.

**G1 is local-only.** PostgreSQL/kind execution, mocked AWS IaC, and pending external
integrations are separate evidence categories. No AWS resources are provisioned.
This project demonstrates engineering practice, not employment history,
certification, financial processing, production readiness, or cloud availability.

G1 is reviewed and merged into develop. G2-A adds an
[offline state-bootstrap design](infra/state-bootstrap/README.md): disabled-by-default
S3/KMS storage, native-lock access contracts and stricter Atlantis project boundaries.
AWS resources, identities, remote state and webhook execution remain unactivated.
See the [G2-A verification record](docs/evidence-g2-a.md).

## Reproduce locally

Use Linux x86_64, Docker, GNU Make, Git, Python 3.12+ for the installer, and `ip`.
The installer pins kubectl, application Python 3.14.10 and all bundled
tools. Allow at least 20 GiB free disk and 10 GiB available RAM; Jenkins runs
separately. Bootstrap downloads verified official artifacts into this checkout.

```bash
make doctor bootstrap
make check test infra-test helm-check
make image lab-up
make e2e
make atlantis-test
```

`make lab-up` installs Helm releases directly for unpublished local development.
After publishing the exact commit, exercise GitOps instead:

```bash
make image
bash scripts/lab-up.sh gitops "$(git rev-parse HEAD)"
make e2e
```

`make evidence GATE=core` runs the shared gates and records SHA, dirty-worktree
status, versions, exit code, and fresh report hashes. Other gates are `infra`,
`security`, `atlantis`, `e2e`, `jenkins`, `state`, and `state-plan`.
A failed command remains failed evidence.
`make jenkins-test` requires a clean committed snapshot and executes Jenkinsfile
on a separate agent; the controller has zero executors and no Docker socket.

## Explore the infrastructure diagram

The [Archify views](docs/diagrams/README.md) separate the local laboratory,
delivery controls, planned AWS foundation and inactive state bootstrap.
Official AWS Architecture Icons are stored locally; preview needs no CDN or AWS access.

```bash
make diagram                     # http://127.0.0.1:8765/
make diagram DIAGRAM_PORT=8877    # http://127.0.0.1:8877/
```

Stop with **Ctrl-C**. The server binds only to loopback and serves the allowlisted
public diagram files, never the repository root. Python 3.12+ is sufficient for
preview/checks; no laboratory startup is required.

Every PR changing mapped infrastructure sources must review the diagrams, regenerate
changed views and pass `make diagram-check` (also included in `make check` and CI).
Changes to cited source bytes require committing the reviewed source, re-pinning
its revision in the models and rebuilding the views. When topology is unchanged,
record why it still applies with `make diagram-refresh NOTE="Reviewed <change>; topology unchanged because <reason>"`.
This checks source/artifact hashes and matching passing Archify build receipts,
then records a dated note. It does not grant human approval or prove complete
semantic fidelity. See the [diagram maintenance procedure](docs/diagrams/README.md).

## Local service contract

The API exposes `POST /v1/events`, `GET /v1/incidents`, and
`POST /v1/incidents/{id}/resolve`. Event ingestion requires an idempotency key; API operations
require a locally generated bearer token. `/healthz`, `/readyz`, and `/metrics`
are internal endpoints. OpenAPI is generated by FastAPI. Read the runbook before
port-forwarding; services bind to loopback and secrets stay in ignored `.local/`.

The observability stack is Prometheus, Grafana, OpenTelemetry Collector, and Tempo.
Logs are JSON stdout; no centralized historical log search is claimed.
Terraform/Terragrunt validate AWS VPC/S3/IAM foundations with mock providers.
`make state-test` focuses on the separate state bootstrap. After `make image`,
`make state-plan-test` verifies the default zero-resource graph with the real
provider, synthetic SDK inputs and networking physically disabled. It is a Docker
check separate from the credential-free mocked tests and does not validate AWS.
Atlantis smoke proves its isolated server and command restrictions; GitHub webhook
and PR-triggered plans remain pending.

## Review and cleanup

Development uses `feature/* → develop → release/* → main`. `renanfenrich` owns
development/Git flow, and `octavariumdigitalpartners` must approve PRs.
Codex stops at **READY FOR HUMAN REVIEW**. No merge or cloud activation is automatic;
local Argo reconciliation follows the explicitly selected published SHA.

`make down` removes only the named local kind cluster and Compose services.
The cluster's synthetic database is disposable: export a backup first if needed.
It does not prune Docker, remove other projects, or delete local credentials.
